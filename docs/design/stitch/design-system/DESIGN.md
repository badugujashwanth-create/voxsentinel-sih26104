## Brand & Style

This design system delivers an ultra-premium, cinematic operational environment tailored for high-stakes enterprise cybersecurity, mission-critical fraud operation centers, and tier-one fintech institutions. The interface establishes absolute forensic authority, precision telemetry, and deliberate restraint.

### Aesthetic Paradigm
- **Tactical Minimalist Cinema:** Reject frivolous neon glows, ambient drop-shadow spam, and generic dashboard widgets. The environment is composed of architectural deep graphite and navy planes separated by razor-sharp hairline borders.
- **Signal-to-Noise Purity:** 90% of the viewport remains anchored in low-luminance neutral planes so that dynamic audio telemetry and actionable alerts cut through with immediate, instinctive clarity.
- **Forensic Rigor:** Visual indicators communicate strict certainty. Acoustic spectrums, harmonic signatures, and threat probabilities are displayed with mathematical legibility rather than decorative gamification.
- **Target Audience:** Security Operations Center (SOC) directors, financial fraud response leads, and executive risk committees monitoring voice cloning, conversational deepfakes, and high-value wire authorization calls in real time.

## Colors

The palette is engineered around high functional contrast, calibrated luminance levels, and semantic isolation. Color is strictly functional; it is never applied arbitrarily for visual decoration.

### Neutral Foundation
- **Canvas Base (`#080a0f`):** The foundational substrate. Deep void graphite with faint desaturated cold navy undertones.
- **Surface Level 1 (`#0f121a`):** Primary workspace panels, analysis trays, and structural sections.
- **Surface Level 2 (`#151a24`):** Secondary nested containers, table row highlights, and active telemetry blocks.
- **Hairline Dividers (`#1e2533` / `#283244`):** Subdued 1px perimeter outlines, grid delineators, and structural framing.

### Typography Levels
- **High-Luminance Primary (`#f8fafc`):** Metrics, real-time transcript words, critical status headlines.
- **Secondary Readout (`#cbd5e1`):** Body context, descriptive telemetry values, active menu states.
- **Muted Metadata (`#8892b0`):** System specs, table headers, unit labels, inactive tooltips.
- **Structural Inactive (`#475569`):** Disabled inputs, empty track visualizer channels, unpopulated matrix cells.

### Functional State Channels
- **Acoustic Waveform Cyan (`#06b6d4` / `#38bdf8`):** Reserved exclusively for live audio stream ingestion, neural spectral synthesis, confidence intervals, and legitimate human harmonic frequencies.
- **Threat Emerging Tactical Amber (`#f59e0b` / `#fbbf24`):** Signals non-standard acoustic jitter, synthesis artifacts, biometric mismatch thresholds, and human review routing.
- **Critical Breach Crimson (`#ef4444` / `#dc2626`):** Strictly restricted to verified synthetic voice clones, impersonation triggers, automated wire isolation, and immediate transaction terminations.
- **Forensic Verification Emerald (`#10b981`):** Subdued, authoritative clearance strictly for completed multi-factor biometric resolution, authentic cryptographically signed vocal tokens, and legitimate caller clearance.

## Typography

Typography establishes an uncompromising split between human-readable editorial clarity and computational machine precision.

### Type Hierarchy Strategy
- **Geist (Primary Sans):** Used for analytical headlines, forensic case descriptions, caller metadata, and system navigation. It maintains optimal legibility across wide viewing angles in incident command centers.
- **JetBrains Mono (Signal Telemetry):** Deployed strictly for technical annotations: timestamps, frequencies (e.g., `44.1 kHz`, `180 Hz - 3.4 kHz`), spectrogram latency readings, packet integrity metrics, vocal tract formant ratios (F1–F4), and threat vector hashes.
- **Tabular Figures:** All dynamic numerical instances utilize monospaced tabular numerals to prevent visual shudder during live multi-channel voice packet parsing.
- **Letter Spacing:** Headlines utilize tight negative tracking to preserve structural solidity, while all uppercase technical labels leverage expanded tracking (`+0.04em` to `+0.06em`) for immediate perceptual parsing in dimly lit command bays.

## Layout & Spacing

The layout model abandons decorative card sprawl in favor of an asymmetric, signal-driven forensic console.

### Layout Mechanics
- **Structural Framing:** A 16-column desktop spatial grid structured around hairline borders (`1px solid #1e2533`). Gutters and margins collapse into structural containment boundaries, producing edge-to-edge geometric precision reminiscent of audio mastering suites and radar telemetry consoles.
- **Breakpoint Framework:**
  - **Desktop Large (≥1600px):** 16-column split. Dynamic acoustic oscilloscopes and harmonic spectrograms occupy the primary visual runway (10 columns), flanked by call metadata, risk score velocity, and active mitigation triggers (6 columns).
  - **Desktop Standard (1200px – 1599px):** 12-column grid. Audio telemetry occupies 8 columns; analytical timeline and decision matrix occupy 4 columns.
  - **Tablet (768px – 1199px):** 8-column layout. Waveform monitor anchors the upper plane; security flags collapse below into continuous vertical feed rails.
  - **Mobile (<768px):** 4-column operational layout. Complex waveforms reduce to linear confidence score strips, live frequency status badges, and prioritized mitigation action sheets.
- **Rhythm & Whitespace:** Component padding relies on the strict multiples of `0.5rem` (`space-sm`) and `1rem` (`space-md`). Dense technical groups are spaced by `space-xs` (4px) to retain spatial coupling, while high-level analytical domains are decoupled by `space-xl` (40px) to prevent cognitive overload during active security escalations.

## Elevation & Depth

Depth is established through calibrated dark surface tonality, architectural layering, and hairline border delineation rather than simulated light-source drop shadows.

### Elevation Schema
- **Base Substrate (`#080a0f`):** The persistent canvas level, non-interactive visual horizon.
- **Surface Level 1 (`#0f121a`):** Primary monitoring planes. Bordered by `1px solid #1e2533`. Zero drop shadow.
- **Surface Level 2 (`#151a24`):** Flyouts, inspector panels, audio segment detail drawers. Bordered by `1px solid #283244`.
- **Active Threat Isolation Layer:** When a call enters an anomalous or breached state, the background remains neutral while the container boundary transitions to a controlled 1px perimeter of `#f59e0b` (Amber Alert) or `#ef4444` (Critical Intercept). No ambient outer blur or glowing drop shadows are permitted.

### The Signature Acoustic Motif
- **Harmonic Confidence Band:** Audio traces are displayed over a dark raster matrix. The visual signature features razor-thin (1.5px) vector strokes for genuine vocal resonance (`#06b6d4`), enveloped by a faint semi-transparent confidence variance band (`rgba(6, 182, 212, 0.08)`).
- **Synthetic Discontinuity Lines:** Detected AI voice artifacts (e.g., vocoder phase mismatch, synthetic pitch stability) are marked by vertical hairline calipers rendered in crimson or amber with precise micro-metric coordinate badges.

## Shapes

The design system employs an engineered, structural shape language prioritizing crisp edges and minimal radii.

### Geometry Specifications
- **Base Geometry (`roundedness: 1`):** Precision radius of `4px` (`0.25rem`) applied to operational buttons, telemetry cells, input fields, and alert badges. Larger panel modules maintain a maximum radius of `8px` (`0.5rem`).
- **Zero-Radius Alignment (`0px`):** Spectrogram viewing ports, vertical timeline splitters, audio scrubbing frames, and edge-to-edge data tables use strictly sharp `0px` boundaries to emphasize technical precision.
- **Corner Badges & Technical Notches:** Specialized analytical viewports may utilize 45-degree chamfered corner cuts (3px) or micro crosshair hairline intersections (`+`) at panel junctions to reinforce the forensic instrument aesthetic.

## Components

### 1. Action & Mitigation Buttons
- **Primary Tactical Action:** Background `#06b6d4`, typography `#080a0f` (bold Geist), border: none, radius: 4px, height: 36px, internal padding: 0 16px. Used for neutral operations such as "Export Audio Forensic Log" or "Initialize Identity Handshake".
- **Critical Mitigation (Terminate / Isolate):** Background `#dc2626`, typography `#ffffff`, radius: 4px, height: 40px. Distinct high-priority styling. Hover state shifts to `#ef4444` with zero ambient blur.
- **Ghost Action:** Background transparent, border: `1px solid #283244`, typography `#cbd5e1`. Hover state elevates border to `#8892b0` and background to `rgba(255, 255, 255, 0.03)`.

### 2. Forensic Audio Chips & Status Badges
- **Form Factor:** Compact height (20px–24px), font: `JetBrains Mono` 10px / uppercase / tracking `+0.05em`, radius: 3px.
- **Live Stream Indicator:** Transparent cyan background (`rgba(6, 182, 212, 0.1)`), hairline border `rgba(6, 182, 212, 0.3)`, text `#38bdf8`. Prefixed with a static 4px cyan square.
- **Synthetic Voice Detected:** Background `rgba(239, 68, 68, 0.15)`, hairline border `#ef4444`, text `#f87171`. Prefixed with an alert icon glyph.
- **Cryptographically Verified:** Background `rgba(16, 185, 129, 0.1)`, hairline border `#10b981`, text `#34d399`.

### 3. Data Tables & Call Telemetry Lists
- **Structure:** Flush full-width grid layouts separated by hairline `1px solid #1e2533` rules. Alternating row fills are prohibited; hover state is indicated by a subtle background shift to `#151a24`.
- **Data Alignment:** Audio stream labels and caller IDs are set in `Geist` 13px left-aligned; all risk scores, Hz ratings, millisecond latencies, and transaction amounts are set in `JetBrains Mono` 12px right-aligned.

### 4. Input Fields & Parameter Sliders
- **Inputs:** Background `#0f121a`, border `1px solid #283244`, text `#f8fafc`, typography `Geist` 14px. Focus state strictly changes border to `#06b6d4` with no box-shadow spread.
- **Acoustic Threshold Sliders:** Track height 2px (`#1e2533`), filled range indicator `#06b6d4` (or `#ef4444` if setting critical risk limits), thumb is a solid 10px rectangular block `#f8fafc` with 1px border.

### 5. Specialized Domain Components
- **Voice Fingerprint Spectrogram Container:** Fixed dark void display (`#05070a`) framed by `1px solid #1e2533`. Includes integrated frequency rulers on the Y-axis (0–8 kHz) in `JetBrains Mono` 10px `#475569`, and timeline scrubbing scrubhead anchored on the X-axis.
- **Harmonic Confidence Band:** A multi-layered SVG visualization displaying detected human vocal tract formant envelopes against neural TTS prediction lines.
- **Identity Resolution Card:** Minimalist panel (`#0f121a`) featuring zero elevation drop shadow, an active latency counter (`ms`), out-of-band biometric verification status badge, and caller historical risk score delta sparkline.
